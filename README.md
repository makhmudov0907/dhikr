# Dhikr: Build Your Habit

Минимальный бесплатный счётчик зикра с одной оливой, личной дневной целью и локальным сохранением. Эта папка — готовый статический сайт: сборка, npm и серверная база данных для публикации не нужны.

Версия: 2026-11-18-1.

## Что уже работает

- Один выбранный зикр: Астагфируллах, Субханаллах, Альхамдулиллях или Аллаху акбар.
- Собственная дневная цель, счётчик, отмена случайного нажатия и анимация капель.
- Постепенное озеленение оливы. Если вчерашняя цель выполнена, зелёный вид сохраняется в течение следующего дня. Если вчерашняя цель не выполнена, дерево начинает новый день сухим и оживает от сегодняшнего прогресса.
- Новый счёт каждый день по локальной дате устройства. Предыдущие записи сохраняются.
- Изменение плана пересчитывает сегодняшний прогресс, сохраняя выполненные повторения каждого зикра.
- Иконка и запуск в отдельном окне на поддерживающих установку устройствах.
- Работа без интернета после успешного сохранения файлов приложения.

## 1. Опубликовать на GitHub Pages

### Создать репозиторий

1. Войдите в свой аккаунт на https://github.com/.
2. Нажмите **+ → New repository**.
3. Введите название, например **dhikr**.
4. Выберите **Public**. Для публичного репозитория GitHub Pages доступен на бесплатном GitHub Free. Исходный код будет открыт для просмотра.
5. Включите **Add README** и нажмите **Create repository**.

### Загрузить готовые файлы

1. Распакуйте `Dhikr_GitHub_PWA.zip` на компьютере.
2. В репозитории нажмите **Add file → Upload files**.
3. Загрузите содержимое распакованной папки: все файлы и папки, включая `assets` и `tests`. Загружать сам ZIP не нужно.
4. Нажмите **Commit changes** и сохраните файлы в **main**.
5. Проверьте, что `index.html` виден сразу в корне репозитория. Он не должен оказаться внутри дополнительной папки `Dhikr_GitHub_PWA` или `dist`.
6. В корне должен быть пустой файл `.nojekyll`. На Mac он может быть скрыт. Если файл не загрузился, выберите **Add file → Create new file**, назовите его `.nojekyll` и сохраните. Пустой файл отключает лишнюю обработку Jekyll.

В корне должны находиться `index.html`, `style.css`, `app.mjs`, `logic.mjs`, `pwa.mjs`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `README.md`, папки `assets` и `tests`.

### Включить сайт

1. Откройте **Settings → Pages** именно внутри репозитория.
2. В **Build and deployment** установите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/(root)`
3. Нажмите **Save**.
4. Дождитесь публикации: по документации GitHub это может занять до 10 минут. Результат сборки можно посмотреть во вкладке **Actions**.
5. Вернитесь в **Settings → Pages** и нажмите **Visit site**.

Адрес будет похож на `https://ВАШ-ЛОГИН.github.io/dhikr/`. Это пример: используйте точный адрес из **Visit site**. Код менять под логин или название репозитория не нужно — пути в приложении относительные. Адреса `github.io` используют HTTPS.

## 2. Установить значок

### iPhone — Safari

1. Откройте опубликованную ссылку в **Safari**.
2. Нажмите **Поделиться**; в некоторых вариантах Safari сначала откройте меню страницы.
3. Выберите **На экран «Домой»**.
4. Если есть параметр **Открыть как веб-приложение**, включите его.
5. Оставьте имя **Dhikr** и нажмите **Добавить**.
6. Откройте Dhikr через появившийся значок, пока интернет ещё включён.

Если действия «На экран Домой» нет, откройте «Редактировать действия» внизу меню «Поделиться». Названия и расположение пунктов могут зависеть от версии iOS.

### Android — Chrome

1. Откройте опубликованную ссылку в **Chrome**.
2. Откройте меню **⋮ → Установить и создать ярлык → Установить**. В некоторых версиях пункт называется «Установить приложение» или «Добавить на главный экран».
3. Подтвердите установку и откройте приложение через значок.

Если браузер поддерживает предложение установки, в окне «План» самого Dhikr также появится кнопка **Установить Dhikr**.

### Компьютер

В Chrome откройте сайт, затем меню **⋮ → Cast, save, and share → Install page as app…**; названия будут переведены при русском языке браузера. При доступности также можно нажать значок установки в адресной строке.

## 3. Проверить перед отправкой друзьям

1. Откройте сайт и установите удобный план. Для короткой проверки можно выбрать цель 3.
2. Добавьте одно повторение и обновите страницу — счёт должен сохраниться.
3. Завершите цель — олива должна стать зелёной.
4. Откройте **План** и дождитесь сообщения **Готово к работе без интернета**. Оно означает, что файлы приложения сохранены.
5. Добавьте значок на главный экран. После установки ещё раз откройте приложение с интернетом и проверьте статус в «Плане».
6. Отключите интернет и заново откройте Dhikr через значок. Проверьте счёт и сохранение, затем верните подключение.
7. Отправляйте друзьям опубликованную ссылку из GitHub Pages и короткие шаги установки для их телефона.

Появление значка само по себе не означает, что все файлы уже сохранены для офлайн-работы. Если статус говорит, что подготовка не завершилась, откройте сайт с интернетом ещё раз.

## Сохранения и ограничения

План и записи находятся в `localStorage` браузера, а не в репозитории GitHub. Аккаунта и синхронизации устройств нет. Очистка данных сайта, приватный режим и удаление данных браузера могут лишить пользователя сохранений.

Старая ссылка `chatgpt.site` и новый адрес GitHub — разные сайты с разными хранилищами: автоматического переноса прогресса между ними нет. После публикации пользуйтесь одной окончательной ссылкой и одной установленной копией. Не рассчитывайте на автоматический перенос из вкладки браузера в установленную оболочку на любой платформе.

Считайте в одной активной вкладке: строго одновременные нажатия в разных вкладках могут перезаписать друг друга. Дни определяются часами устройства; защиты от ручного изменения времени в этой минимальной версии нет.

## Как обновлять приложение

Для следующих готовых версий загрузите обновлённый комплект файлов в тот же репозиторий и ветку `main`. Ссылка останется прежней.

Если самостоятельно изменяете код, CSS, изображения или манифест, измените также `VERSION` в начале `sw.js`, например с `2026-11-18-1` на `2026-11-18-2`. Затем загрузите весь обновлённый комплект. Это нужно, чтобы уже установленные копии получили новые файлы.

Обновление загружается при подключении к интернету и активируется после закрытия всех вкладок и окон Dhikr. Во время счёта приложение само не перезагружается. При доступном обновлении сообщение появится в «Плане». Обновление файлов приложения не удаляет записи из `localStorage`; не меняйте ключ хранения без миграции данных.

## Для разработки

Файлы можно редактировать обычным редактором кода. Никаких внешних шрифтов, JavaScript-библиотек или API-ключей не требуется. `assets/icons/icon.svg` — редактируемый исходник значка с водяной буквой i; для установки используются уже готовые PNG.

Локальный запуск из папки распакованного архива, если установлен Python:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Не запускайте `index.html` двойным щелчком через `file://`: JavaScript-модули и service worker требуют HTTP(S), при локальной разработке подходит localhost.

Проверки при установленном Node.js 20 или новее:

```bash
node --test tests/*.test.mjs
```

`logic.test.mjs` проверяет дневные цели, даты, пропуски и сохранения. `pwa.test.mjs` проверяет пути, ресурсы манифеста, кэширование, офлайн-ответы и изоляцию разных установок. Проверки service worker на Node используют моделируемую среду и не заменяют установку на реальный телефон.
